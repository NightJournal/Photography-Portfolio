# Photo Upload Folders

Use these folders for gallery photos:

- `asia/`
- `south-africa/`
- `europe/`
- `north-america/`
- `astrophotography/`
- `dolomites/`

Suggested naming pattern:

- `photo-01.jpg`
- `photo-02.jpg`
- `photo-03.jpg`

After adding photos, update the matching gallery page image paths to point to the uploaded files.
